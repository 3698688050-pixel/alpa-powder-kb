# ALPA 粉体选型知识库

山东埃尔派粉体科技（Shandong ALPA Powder Technology）的超微粉碎与分级设备学习库。
目标不是背参数，而是**在客户说出物料和粒度的那一刻，能给出路线、机型和一个站得住的理由**。

在线站点：开启 GitHub Pages 后访问仓库根目录的 `index.html`。

---

## 里面有什么

| 模块 | 内容 |
|---|---|
| 总览 | 产品谱系图：所有设备只回答「磨细」还是「切段」两个问题 |
| 学习路径 | 六步，从零到能对客户讲，含三道自测题 |
| 产品库 | 17 个系列，每个给粒度区间、产能、设计特点、**边界与代价**、出处 |
| 选型决策 | 核心页：粒度定路线 → 物料属性做否决 → 同族横向差异 → 口径陷阱 → 必问清单 → 速答 |
| 行业方案 | 11 个行业，结构统一为「客户的难处 → 公司的答法 → 用什么设备」 |
| 物料与目数 | 37 种物料的密度/莫氏硬度/易磨性，以及目数与微米对照 |
| 术语 | 20 条，D50/D97 到 CIP/SIP、DQ/IQ/OQ/PQ |

全站支持关键词搜索（无依赖，索引在浏览器内构建）。

## 数据从哪来

| 代码 | 来源 |
|---|---|
| `manual` | 《员工培训手册》2022 内部版，10 章 125 页 |
| `catalogue` | 2024 版产品样册（分级机样册可读；两份机械粉碎样册上传时被截断，未能解析） |
| `web_cn` | 中文官网 www.alpapowder.cn |
| `web_en` | 英文官网 www.alpapowder.com |

每条产品、每条选型规则都带 `source` 字段。**没有出处的推断不写进来。**
手册与官网口径冲突处两说并存并标注（例如流化床分级转子线速度：手册写 80m/s，官网写 65m/s 陶瓷转子）。

## 仓库结构

```
alpa-kb/
├── data/                 唯一事实来源（人只改这里）
│   ├── products.yaml     产品主数据，17 条
│   ├── decision.yaml     选型规则：粒度路线 / 物料否决 / 横向差异 / 商务
│   ├── industries.yaml   行业方案，11 条
│   ├── materials.json    物料属性，37 条（从手册表格解析）
│   └── mesh.json         目数换算，37 档
├── site/                 源文件：html 壳 + css + 前端 js
├── docs/                 构建产物（GitHub Pages 直接托管这个目录）
├── build.py              生成器：yaml/json → docs/kb.json + 拷贝静态资源
└── check.sh              回归自检
```

## 本地构建

```bash
python3 -m pip install pyyaml   # 唯一依赖
python3 build.py                # 产物进 docs/
python3 -m http.server -d docs 8000
```

前端是原生 JS，零构建、零 CDN、离线可用。`docs/` 可直接双击 `index.html` 打开
（但 `file://` 下 `fetch` 会被拦截，请用 http server 或 Pages）。

## 加内容

1. 改 `data/*.yaml`，按现有字段写，**新字段必须带来源**。
2. `python3 build.py`
3. `./check.sh` 必须全绿再提交。

## 质量闸

- `check.sh` 里的 `slopcheck` 要求 **0 FAIL**；对比度全部 ≥ 4.5:1（正文最低 4.68，标签最低 4.99）。
- 正文最小 13px，11px 只用于标签与表头。
- 移动端无横向溢出，宽表在容器内独立滚动。
